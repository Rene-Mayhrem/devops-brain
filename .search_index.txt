./copilot/skills/obsidian-cli/SKILL.md:18:## Capability probe and fallback
./copilot/skills/obsidian-cli/SKILL.md:19:
./copilot/skills/obsidian-cli/SKILL.md:20:Copilot exposes the terminal-capable executable from the running Obsidian
./copilot/skills/obsidian-cli/SKILL.md:21:installation as <code>COPILOT_OBSIDIAN_CLI</code> when it can resolve one.

./copilot/skills/obsidian-cli/SKILL.md:23:always invoke it as a quoted executable rather than constructing a command
./copilot/skills/obsidian-cli/SKILL.md:24:string. Before relying on the CLI, probe it using the active shell:
./copilot/skills/obsidian-cli/SKILL.md:25:
./copilot/skills/obsidian-cli/SKILL.md:26:~~~bash
./copilot/skills/obsidian-cli/SKILL.md:27:obsidian_cli="${COPILOT_OBSIDIAN_CLI:-obsidian}"
./copilot/skills/obsidian-cli/SKILL.md:28:"$obsidian_cli" version
./copilot/skills/obsidian-cli/SKILL.md:29:~~~
./copilot/skills/obsidian-cli/SKILL.md:30:
./copilot/skills/obsidian-cli/SKILL.md:31:~~~powershell
./copilot/skills/obsidian-cli/SKILL.md:32:$obsidianCli = if ($env:COPILOT_OBSIDIAN_CLI) { $env:COPILOT_OBSIDIAN_CLI } else { "obsidian" }
./copilot/skills/obsidian-cli/SKILL.md:33:& $obsidianCli version
./copilot/skills/obsidian-cli/SKILL.md:34:~~~
./copilot/skills/obsidian-cli/SKILL.md:35:
./copilot/skills/obsidian-cli/SKILL.md:36:A command being present on PATH is not sufficient: the probe must exit
./copilot/skills/obsidian-cli/SKILL.md:37:successfully. Use the selected executable in place of <code>obsidian</code> in
./copilot/skills/obsidian-cli/SKILL.md:38:the examples below, resolving it again in a later shell call when necessary. If
./copilot/skills/obsidian-cli/SKILL.md:39:the probe fails, continue with ordinary filesystem tools where they can satisfy
./copilot/skills/obsidian-cli/SKILL.md:40:the request. Briefly tell the user only when the missing runtime capability
./copilot/skills/obsidian-cli/SKILL.md:41:matters. Do not install Obsidian, change PATH, register the CLI, or raise the
./copilot/skills/obsidian-cli/SKILL.md:42:plugin's minimum Obsidian version on the user's behalf.
./copilot/skills/obsidian-cli/SKILL.md:43:
./copilot/skills/obsidian-cli/SKILL.md:44:The CLI requires a compatible Obsidian installer and a running app. Commands
./copilot/skills/obsidian-cli/SKILL.md:45:can differ by version, so inspect live help before using a command whose syntax
./copilot/skills/obsidian-cli/SKILL.md:46:is not already established:

./copilot/skills/obsidian-cli/SKILL.md:54:interface** using a compatible installer. Leave registration and any platform

./copilot/skills/obsidian-cli/SKILL.md:100:### Inspect open notes
./copilot/skills/obsidian-cli/SKILL.md:101:
./copilot/skills/obsidian-cli/SKILL.md:102:When the user asks about notes currently open in Obsidian:
./copilot/skills/obsidian-cli/SKILL.md:103:
./copilot/skills/obsidian-cli/SKILL.md:104:~~~bash
./copilot/skills/obsidian-cli/SKILL.md:105:obsidian vault="My Vault" tabs ids
./copilot/skills/obsidian-cli/SKILL.md:106:obsidian vault="My Vault" workspace ids
./copilot/skills/obsidian-cli/SKILL.md:107:~~~
./copilot/skills/obsidian-cli/SKILL.md:108:
./copilot/skills/obsidian-cli/SKILL.md:109:Use <code>tabs ids</code> as the source of truth for open tabs. Keep entries
./copilot/skills/obsidian-cli/SKILL.md:110:verbatim and classify them only when the output provides enough evidence:
./copilot/skills/obsidian-cli/SKILL.md:111:
./copilot/skills/obsidian-cli/SKILL.md:112:- a Markdown note has an explicit vault path ending in <code>.md</code>
./copilot/skills/obsidian-cli/SKILL.md:113:  (case-insensitive)
./copilot/skills/obsidian-cli/SKILL.md:114:- another file-backed tab has an explicit vault path with a different extension
./copilot/skills/obsidian-cli/SKILL.md:115:- a non-file view, such as search, graph, settings, or a plugin view, has no
./copilot/skills/obsidian-cli/SKILL.md:116:  vault path
./copilot/skills/obsidian-cli/SKILL.md:117:
./copilot/skills/obsidian-cli/SKILL.md:118:Do not infer a path from a display title, view type, or tab ID, and do not
./copilot/skills/obsidian-cli/SKILL.md:119:discard entries that cannot be classified. For a request about open notes,
./copilot/skills/obsidian-cli/SKILL.md:120:extract the Markdown paths while retaining the other tabs as workspace context.
./copilot/skills/obsidian-cli/SKILL.md:121:Use <code>workspace ids</code> when tab groups or workspace hierarchy matter. Do
./copilot/skills/obsidian-cli/SKILL.md:122:not substitute <code>recents</code>, which includes files that are no longer open.
./copilot/skills/obsidian-cli/SKILL.md:123:
./copilot/skills/obsidian-cli/SKILL.md:124:If the tab output does not expose paths or view types clearly, correlate its tab
./copilot/skills/obsidian-cli/SKILL.md:125:IDs with this read-only, structured workspace query:
./copilot/skills/obsidian-cli/SKILL.md:126:
./copilot/skills/obsidian-cli/SKILL.md:127:~~~bash
./copilot/skills/obsidian-cli/SKILL.md:128:obsidian vault="My Vault" eval code='JSON.stringify((()=>{const tabs=[];const active=app.workspace.getMostRecentLeaf();app.workspace.iterateAllLeaves(leaf=>{const path=leaf.view.file?.path??null;tabs.push({id:leaf.id,title:leaf.getDisplayText(),viewType:leaf.view.getViewType(),path,kind:path===null?"view":path.toLowerCase().endsWith(".md")?"markdown":"file",active:leaf===active})});return tabs})())'
./copilot/skills/obsidian-cli/SKILL.md:129:~~~
./copilot/skills/obsidian-cli/SKILL.md:130:
./copilot/skills/obsidian-cli/SKILL.md:131:The workspace query also returns sidebar and floating leaves. Only call an entry
./copilot/skills/obsidian-cli/SKILL.md:132:an open tab when its ID appears in <code>tabs ids</code>; retain query-only
./copilot/skills/obsidian-cli/SKILL.md:133:entries separately as workspace context. Preserve tab entries that have no
./copilot/skills/obsidian-cli/SKILL.md:134:matching workspace entry instead of guessing their identity.
./copilot/skills/obsidian-cli/SKILL.md:135:
./copilot/skills/obsidian-cli/SKILL.md:136:If the user asks for the single currently focused note and the tab output does
./copilot/skills/obsidian-cli/SKILL.md:137:not identify it, use a read-only app query:
./copilot/skills/obsidian-cli/SKILL.md:138:
./copilot/skills/obsidian-cli/SKILL.md:139:~~~bash
./copilot/skills/obsidian-cli/SKILL.md:140:obsidian vault="My Vault" eval code="app.workspace.getMostRecentLeaf()?.view.file?.path ?? ''"
./copilot/skills/obsidian-cli/SKILL.md:141:~~~
./copilot/skills/obsidian-cli/SKILL.md:142:
./copilot/skills/obsidian-cli/SKILL.md:143:Use normal filesystem tools only for explicit paths returned by Obsidian, and
./copilot/skills/obsidian-cli/SKILL.md:144:choose a reader appropriate to the file type. Do not read every open note when
./copilot/skills/obsidian-cli/SKILL.md:145:paths or titles alone answer the request.
./copilot/skills/obsidian-cli/SKILL.md:146:
./copilot/skills/obsidian-cli/SKILL.md:147:## Obsidian and plugin commands

./copilot/skills/obsidian-cli/SKILL.md:155:~~~bash

./copilot/skills/obsidian-cli/SKILL.md:180:
./copilot/skills/obsidian-cli/SKILL.md:181:Never reload or restart the Obsidian app or window from an agent session. Never
./copilot/skills/obsidian-cli/SKILL.md:182:reload, disable, or uninstall the Copilot plugin that is hosting the agent. In
./copilot/skills/obsidian-cli/SKILL.md:183:particular, do not use:
./copilot/skills/obsidian-cli/SKILL.md:184:
./copilot/skills/obsidian-cli/SKILL.md:185:- any CLI command that reloads or restarts the app, window, or renderer
./copilot/skills/obsidian-cli/SKILL.md:186:- any plugin reload, disable, or uninstall operation targeting Copilot
./copilot/skills/obsidian-cli/SKILL.md:187:- any restricted-mode change
./copilot/skills/obsidian-cli/SKILL.md:188:- a command ID, JavaScript expression, or CDP call that performs an equivalent
./copilot/skills/obsidian-cli/SKILL.md:189:  app, window, renderer, or Copilot-plugin teardown
./copilot/skills/obsidian-cli/SKILL.md:190:

./copilot/skills/obsidian-cli/SKILL.md:192:hard prohibition, not a confirmation-gated operation. If verification requires
./copilot/skills/obsidian-cli/SKILL.md:193:one, finish all non-destructive checks and tell the user to perform the reload
./copilot/skills/obsidian-cli/SKILL.md:194:manually after the agent session has ended.
